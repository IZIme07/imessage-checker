# iMessage Checker

Минималистичное приложение для macOS: проверяет, можно ли отправить iMessage на email или номер телефона.

- Одиночная проверка: введите email или номер и нажмите ↩︎.
- Проверка файла: перетащите в окно CSV / TXT / MD. Приложение найдёт все email и номера, проверит их и покажет таблицу с результатами. Результаты можно выгрузить в CSV.

## Установка

1. Скачайте `iMessage-Checker-<версия>.dmg` из [последнего релиза](https://github.com/IZIme07/imessage-checker/releases/latest).
2. Откройте его и перетащите **iMessage Checker** в «Программы».
3. При первом запуске macOS предупредит, что разработчик не установлен. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть».

Обновления ставятся сами: при каждом запуске приложение проверяет последний релиз на GitHub, скачивает новую версию, проверяет её подпись и перезапускается.

## Как это работает

Приложение использует приватный системный фреймворк `IDS` — тот же, через который Messages подсвечивает адресата синим или зелёным. Запросы идут через Apple ID, под которым вы вошли в iMessage на этом Mac. Никаких кредов в приложении нет.

Это приватный API Apple: он может перестать работать после обновления macOS.

## Лимиты

- до 20 адресов в одном запросе (Apple разрешает до 35);
- 3 секунды между запросами;
- не больше 500 проверок в час, счётчик сохраняется между запусками;
- если Apple вернула ошибку, пауза 15 минут и повтор.

## Сборка

Нужны macOS 14+ и Xcode Command Line Tools.

```sh
./build.sh
open "iMessage Checker.app"
```

## Выпуск релиза

1. Один раз: `swift Scripts/sign-update.swift generate` — создаёт ключ подписи обновлений в `~/.config/imessage-checker/` (в репозиторий не попадает) и печатает публичный ключ, он должен совпадать с `Updater.publicKey` в `Sources/main.swift`.
2. Поднимите версию в файле `VERSION`, закоммитьте.
3. `./release.sh` — соберёт DMG и подписанный ZIP и опубликует релиз на GitHub.
